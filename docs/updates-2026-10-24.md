# EDITH update — 24 October 2026

## Management

ปรับหน้า Management ใน Local mode เป็น **Workspace & access** พร้อมสถานะ Local mode และการ์ดสองส่วน:

- **Current workspace:** ข้อมูล Local owner, การเข้าถึง workspace และปุ่ม Open Network Inspector
- **Work with a team:** อธิบายบัญชีและ roles พร้อม Set up Team mode ที่ขยายขั้นตอนและคัดลอก `npm run dev:team` ได้

ซ่อนแถบ SDK connection เฉพาะหน้า Management เพื่อให้หน้านี้โฟกัสเรื่อง workspace และสิทธิ์ การเปลี่ยนโหมดต้อง restart server ตามเดิม และไม่เริ่ม Team mode จากการกดดูคำแนะนำ อ่านรายละเอียดใน [Accounts](accounts.md)

## Proxy settings

แบ่งการตั้งค่าเป็นสามแท็บที่รองรับคีย์บอร์ดและหน้าจอแคบ:

| แท็บ | การตั้งค่า |
| --- | --- |
| Connection | Listen address, สถานะ local proxy และ System Proxy |
| HTTPS inspection | เปิด–ปิด inspection, All hostnames, Selected และ Excluded hostnames |
| Certificate | สร้างและดาวน์โหลด CA, fingerprint, วันหมดอายุ และวิธีเชื่อถือ CA บน macOS |

HTTPS inspection เริ่มต้นเป็นปิด และจำสวิตช์, All hostnames, โดเมนและข้อยกเว้นไว้ใน local storage ใช้ค่าที่เลือกเมื่อกด Start โดยการโหลดหน้าหรือคืนค่าที่บันทึกไว้ไม่เริ่ม inspection เอง สถานะ **Enabled on next Start** แยกจากสถานะที่กำลังทำงานจริง และยังต้องเชื่อถือ CA ด้วยตนเอง

แก้ปุ่ม Start/Stop และตัวเลือกที่กระพริบระหว่างตรวจสถานะทุกวินาที โดยแยกสถานะ polling ออกจากคำสั่งที่ผู้ใช้กด และไม่นำผล polling เก่ามาเขียนทับคำสั่งใหม่

## System Proxy บน macOS desktop

เพิ่มสวิตช์ **Use EDITH as System Proxy**, ตัวเลือก network service และรายละเอียดสถานะ HTTP/HTTPS ที่อ่านจาก macOS พร้อมปุ่ม Refresh status และ Restore saved settings

ตัวเลือก **Enable System Proxy on Start** เปิดเป็นค่าเริ่มต้นและจำค่ารวมถึง network service ที่เลือกไว้ เมื่อกด Start จะรอให้ local proxy ทำงานก่อนจึงขอเปิด System Proxy หากยกเลิกสิทธิ์หรือเปิดไม่สำเร็จ local proxy ยังทำงานและแสดงข้อผิดพลาด

บันทึกค่าเดิมก่อนเปลี่ยน และคืนค่าก่อน Stop หรือปิดหน้าต่าง desktop ตามปกติ หากคืนค่าไม่ได้จะคงข้อมูล recovery ไว้ การ force quit, crash หรือหยุด development server อาจทำให้ต้อง Restore หลังเปิดแอปใหม่ ไม่เปลี่ยน PAC, SOCKS, bypass list หรือ certificate trust และไม่แทนที่ proxy เดิมที่ใช้ authentication

ใช้ได้ใน **macOS desktop development runtime** เท่านั้น หน้าเว็บและแพลตฟอร์มอื่นแสดงข้อจำกัด ส่วน proxy runtime ยังไม่รวมใน packaged desktop อ่านขั้นตอนและข้อจำกัดใน [คู่มือ Proxy](proxy-user-guide.md)

## Loading และไอคอน

- Loading ใช้ตัวอักษร EDITH ในกรอบมุมโค้ง เลื่อนอ้อมด้านบนจากซ้ายไปขวา พร้อมสี mint ที่ตัวกำลังเลื่อน หนึ่งรอบครบห้าตัวใช้ 3 วินาที
- Session/form loaders แสดงขั้นต่ำ 1.5 วินาที โดยงานจริงที่ใช้เวลานานกว่าจะรอจนเสร็จ รองรับ reduced motion ดู [Loading component](loading-component.md)
- ใช้ไอคอน E สี mint บนพื้น graphite สำหรับ favicon และชุด desktop PNG/ICO/ICNS ไอคอนแอปที่ติดตั้งแล้วต้อง build และติดตั้งใหม่จึงจะรับไอคอนใหม่
- คำสั่งเปิด development แยกการหยุดด้วย Ctrl+C ออกจากความผิดพลาดจริง การหยุดที่ตรวจพบแสดง **EDITH stopped.** ส่วน startup failures และ exit 130 ที่ไม่ได้เกิดจากการขอหยุดยังคงเป็นข้อผิดพลาด

## การตรวจสอบ

Frontend production build และ TypeScript ผ่าน ตรวจหน้า Local Management ในเบราว์เซอร์ รวมถึงการขยายคำแนะนำ Team mode และตรวจ Proxy settings บนหน้าจอแคบแล้ว

ระหว่างพัฒนามีการทดสอบจำลองการคงสถานะปุ่มระหว่าง polling, การจำค่า HTTPS inspection, auto-start System Proxy, opt-out, การยกเลิกสิทธิ์และการคืนค่าตอน Stop แล้ว Native unit tests ผ่าน 4 รายการ และ local proxy tests ผ่าน 10 รายการ การอัปเดตเอกสารครั้งนี้ไม่ได้รันชุดทดสอบเหล่านั้นซ้ำ

ยังไม่ได้ทดสอบการเปลี่ยน System Proxy จริงพร้อมหน้าต่างขอสิทธิ์ macOS แบบครบวงจร และยังไม่ได้ตรวจ visual QA ของ Team flows หรือ native Windows/Linux ครบทุกกรณี
