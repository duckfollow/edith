## EDITH v0.1.0-alpha.4

A new look for EDITH, plus a fix for closing the desktop window.

### What's new

- New smart-glasses logo with mint frames on graphite, styled to match the Dum-E app family.
- Updated sidebar, login branding, browser favicons, macOS Dock icon, and desktop icon assets.
- Reproducible SVG-to-desktop icon generation.

### Fixes

- Fixed the desktop Close button failing to close the window.
- Closing now waits for System Proxy restoration and completes the original close request, without recursive Close calls.
- Repeated close clicks are handled while cleanup is pending.
- If proxy restoration fails or administrator approval is cancelled, EDITH stays open, displays the reason, and allows retry.

### Installation

**Apple Silicon Mac · macOS 13.5 or later**

1. Download `EDITH_0.1.0-alpha.4_aarch64.dmg` below.
2. Stop any active proxy and quit the previous EDITH version.
3. Open the DMG and drag EDITH into Applications, replacing the previous version.
4. Launch EDITH from Applications.

The app includes its local runtime; Node.js, npm, and the project folder are not required. Existing installed-app workspace data stays in the same application data folder. Replacing the app does not automatically import development workspace data.

### Validation

- 63 desktop tests, 6 native Rust tests, and 8 SDK tests passed.
- Frontend type checking and production build passed.
- Regression coverage includes closing without recovery, waiting for restoration, duplicate close clicks, cancellation/failure, and retry.
- SHA-256 checksums are included in `SHA256SUMS.txt`.

### Alpha notes

- The macOS build is ad-hoc signed and has not been notarized by Apple.
- HTTPS inspection requires manually trusting the local CA.
- Windows/Linux installers and OS packet capture are not included.
