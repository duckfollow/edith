# EDITH update — 23 October 2026

Added development-only HTTPS inspection to the local forward proxy. It is off by default and limited to an explicit allowlist of exact DNS hosts on port 443. Other traffic remains an opaque CONNECT tunnel.

Network now has CA readiness/fingerprint/expiry, Admin-only CA creation, public certificate download, domain configuration and manual macOS trust guidance. No system trust or proxy settings are modified automatically. Existing CA files are reused without rotation or overwrite.

The proxy terminates client TLS with short-lived per-host certificates, validates the upstream TLS connection, and forwards HTTP/1.1 requests through the existing bounded capture path. Network shows real methods, paths and bodies for inspected hosts, with TLS errors and upstream failures reported explicitly. Role-based body/credential access filtering still applies.

Tests use temporary CAs and loopback TLS fixtures. See [HTTPS inspection](https-inspection.md) for setup, security boundaries and remaining limitations. HTTP/2, WebSocket inspection, certificate-pinning bypass, client-certificate forwarding and packaged native support are not included.

Added explicit **Inspect all hostnames** mode with exact hostname exclusions. Selected-host mode remains available; IP destinations stay opaque. The UI explains the wider privacy scope and requires Stop/Start to apply. Full desktop tests pass 52 cases and frontend build passes.

Added a [Thai proxy setup and usage guide](proxy-user-guide.md) covering Local/Team startup, macOS Wi-Fi HTTP/HTTPS proxy settings, CA import and SSL trust, error -25294, selected/all-host modes and exclusions, inspection, media troubleshooting, and cleanup. Linked from README, local proxy, HTTPS inspection, and CA docs.
